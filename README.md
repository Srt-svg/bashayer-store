# متجر بشاير | Bashayer Store 🛍️

مشروع واجهة هبوط وتجارة إلكترونية سريعة (Single-Product E-Commerce Landing Page) مصممة ومبنية وفق أفضل الممارسات الهندسية والمعمارية لمشاريع الويب التفاعلية الموجهة للسوق الكويتي والخليجي.

---

## 🏗️ الهيكل المعماري للمشروع (Architecture)

تم بناء المشروع باعتماد مبدأ **فصل المسؤوليات (Separation of Concerns)** لسهولة الصيانة والتطوير وإعادة الاستخدام:

```text
bashayer-store/
├── .github/
│   └── workflows/
│       └── deploy.yml       # أتمتة النشر عبر GitHub Pages (CI/CD)
├── assets/
│   └── images/              # الأصول البصرية والصور
├── css/
│   └── style.css            # التنسيقات المخصصة والخطوط ومؤثرات الحركة
├── js/
│   ├── config.js            # ملف التكوين المركزي (بيانات المتجر والمنتجات والعملات)
│   ├── checkout.js          # منطق التحقق من البيانات، واحتساب الأسعار، والربط
│   └── main.js              # التحكم في واجهة المستخدم والأحداث التفاعلية
├── index.html               # الهيكل الدلالي للواجهة (Semantic HTML5)
└── README.md                # التوثيق التقني للمشروع
```

---

## ⚙️ ملف الإعدادات المركزي (`js/config.js`)

يحتوي هذا الملف على مصدر الحقيقة الوحيد (Single Source of Truth) لكافة بيانات المتجر. يمكنك تغيير أسعار المنتجات، أرقام التواصل، العملات، أو اسم المتجر دون تعديل أي سطر في كود الواجهة.

```javascript
const STORE_CONFIG = {
  storeName: "متجر بشاير",
  storeEnglishName: "Bashayer Store",
  country: "الكويت",
  currency: "د.ك",
  whatsappNumber: "96596682986",
  // ...
};
```

## 🚀 المزايا التقنية

- **متوافق مع الهواتف الذكية (Mobile-First):** تصميم متجاوب 100% يدعم الاتجاه من اليمين لليسار (RTL).
- **التحقق الدقيق من أرقام الهواتف:** التحقق البرمجي من تطابق أرقام هواتف الكويت (الشبكات المعتمدة: زين، أوريدو، STC).
- **تعدد خيارات الدفع:** دعم الدفع عند الاستلام (COD) مع تجهيز روابط الدفع الإلكتروني (KNET / Apple Pay).
- **النشر التلقائي (CI/CD):** مسار عمل GitHub Actions مدمج ينشر التحديثات تلقائيًا بمجرد دفع التغييرات لفرع `main`.

## 🛠️ خطوات التشغيل المحلي والمساهمة

1. استنساخ المستودع:
   ```bash
   git clone https://github.com/Srt-svg/bashayer-store.git
   cd bashayer-store
   ```
2. فتح ملف `index.html` في أي متصفح ويب، أو تشغيل خادم محلي:
   ```bash
   npx serve .
   ```
